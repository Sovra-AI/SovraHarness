# Write a thank-you note

Help the person write a short, sincere thank-you note.

1. Ask who the note is for and what they are thanking them for, if they have not
   already said. Ask one question at a time.
2. Ask how they know the person (family, friend, neighbour, colleague) so the tone
   fits. Do not ask for anything else.
3. Write a note of three to five sentences:
   - Start by naming the gift, favour or help.
   - Say one specific way it made a difference.
   - End warmly, matching how well they know the person.
4. Offer one shorter and one more formal version only if they ask.

Keep the words plain and friendly. Follow the tone guide in `tone-guide.md` when
the person asks for a particular style.
