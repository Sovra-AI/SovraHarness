01

Learn

A laptop learns something new from a chat, a file or an email, and keeps the source.

02

Direction · how a training round runs

Your company trains its own model.

01

Wait until it’s idle

Plugged in, idle, out of hours. It uses whatever chip is there: a graphics card, a Mac, or just the main processor.

02

Learn locally

Each computer trains a small add-on to the model using only the facts and files it is allowed to hold.

03

Blur the lesson

The update is clipped and noise is added on purpose, so no single document can be rebuilt from it.

04

Combine blind

Updates are combined so that the merge only sees the sum, never any one computer’s update.

05

Prove it helps

The new model is tested against the company’s own held-out tests. A round that doesn’t improve it is rejected.

06

Record, then roll out

The round, who took part and the test score go on the ledger. Every computer gets the update, and you can roll back at any time.

Direction · privacy of the lesson

See the lesson. Still can’t rebuild the file.

TravelsA small, noisy update. Useful to the model, useless as a copy.

Finance and engineering hold very different data. Each lesson is steered back towards the shared goal, so no one team pulls the model off course.
