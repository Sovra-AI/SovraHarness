# reveal.js 4.6.1

Vendored from the published package so a deck can open from disk.
MIT license, see `LICENSE`. Upstream: https://revealjs.com

Linked files:

- `dist/reveal.css` and `dist/reveal.js` — the presentation frame and classic script
- `dist/theme/white.css` — the light theme
- `dist/theme/fonts/source-sans-pro/` — the theme’s font, stored locally

Do not load `reveal.esm.js`. A `file://` page cannot import a module.
